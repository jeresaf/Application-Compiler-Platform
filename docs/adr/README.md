# Architecture decisions

`ACCEPTED` records an engineering choice within the authorized scope. `PROPOSED` records investigation, not authorization. Supersession preserves the original record and links the replacement. Acceptance requires rationale, alternatives, scope, evidence, consequences, and validation. No numerical score may be invented where no experiment ran.
